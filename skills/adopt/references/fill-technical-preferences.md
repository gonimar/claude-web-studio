# /adopt — filling `technical-preferences.md` (Phase 1 steps 6–7)

Read from `SKILL.md` Phase 1 step 6. Every field the files answer is written from the facts; the draft is a table field · value · source fact, shown at the Phase 1 write gate.

Fields, by section of `.claude/docs/technical-preferences.md`:
- Project type and Rendering: from the framework and routes.
- Backend: language/runtime, framework, database and cache from compose, API style from schema/openapi/routes, authentication if visible.
- Frontend: framework, build, styles; `vanilla` or `none` when there is none.
- Tests and quality: from `phpunit.xml`, `vitest.config`, `go test`, lint configs. Go: coverage thresholds only when a gate script or CI step enforces them, else `indicator`.
- Infrastructure: containers, CI, deploy from compose/workflows/deploy skills.
  - **Deploy target and delegate** by `.claude/docs/deploy-target-contract.md`: an agent `.claude/agents/*-ops.md` with `deploy-target:` in its frontmatter, or a `scripts/deploy/*.sh`. Detection goes by the frontmatter or the script, never by a command name: a kit that only ships a slash command is noted as `none` with the reason "kit ships only a slash command — add `deploy-target:` to its agent or a `scripts/deploy/<target>.sh`". The Tier 0 row of `agent-roster.md` (Phase 3 step 4) notes the companion the same way.
  - **Infra repo / Proxy config**: asked when the host is shared.
  - **Deploy target `kubernetes`** is detected from the files, not asked: a `Chart.yaml` (with `templates/`), a `kustomization.yaml`, a `deploy/k8s/` or `charts/` directory, `helm`/`kubectl` steps in `.github/workflows/*`. Then the `Kubernetes` sub-block from the same facts — `k8s_chart_path` = the directory holding `Chart.yaml`; `k8s_environments` = the `values-<env>.yaml` files (or `values.<env>.yaml`, overlays under `kustomization.yaml`); `k8s_secrets` = `external-secrets` when an `ExternalSecret`/`SecretStore` manifest exists, `sealed-secrets` for a `SealedSecret`, else `[TO BE CONFIGURED]` with the finding "plain Secret manifests in git" (HIGH → `production/findings.md`); `k8s_routing` = `gateway-api` for an `HTTPRoute`, `ingress` for an `Ingress` (a finding when the controller is ingress-nginx — retired, `kubernetes.md`). Delegate: `script scripts/deploy/kubernetes.sh` when it exists, else `none` and a plan item to write it from `kubernetes.md` § Rollout and rollback. The source fact names the file.
- Observability (`stack-reference/observability.md`), from the manifests and the code — `[TO BE CONFIGURED]` only when nothing answers:
  - `log_format`: `json` when `log/slog` `NewJSONHandler`, Monolog `JsonFormatter` or `pino` is in use; `text — <library>` otherwise (a finding: MEDIUM, "logs are not JSON").
  - `metrics`: `prometheus` when `github.com/prometheus/client_golang` is in `go.mod`, `promphp/prometheus_client_php` in `composer.json` (adapter from the storage class used), `@prometheus-io/client` or `prom-client` in `package.json` (the old name → a plan item to rename); `none` when no client library and no `/metrics` route.
  - `tracing`: `opentelemetry` when `go.opentelemetry.io/otel`, `open-telemetry/sdk` or `@opentelemetry/sdk-node` / `@opentelemetry/api` is a dependency (the sampler from `OTEL_TRACES_SAMPLER` in compose/values/env files, else "not configured"); a vendor agent (Sentry, Datadog, New Relic SDKs) → `custom — <vendor>`; `none` otherwise.
  - `health_endpoints`: the routes found (`/healthz`, `/readyz`, `/health`, `/live`, `/ready`); a single endpoint that queries the database is a finding (MEDIUM, "liveness checks dependencies").
  - The headline **Observability** value: `studio stack` when all four match the reference, `minimal` when only logs and health exist, `custom` otherwise — with the differences listed as the source fact.
  - **Supply chain** (`stack-reference/supply-chain.md`), from the files, never from memory: `update_bot` = `renovate` when `renovate.json` / `.renovaterc*` / `renovate.json5` exists, `dependabot` when `.github/dependabot.yml` exists, `none` otherwise; `release_age` = Renovate `minimumReleaseAge` or Dependabot `cooldown.default-days` (`3 days (Dependabot default)` when unset, `none` for Renovate without the option); `sbom_tool` = `syft` / `trivy` / `none` by the workflow steps (`syft`, `anchore/sbom-action`, `trivy … --format cyclonedx|spdx`); `signing` = `cosign keyless` (a `cosign sign` step without `--key`), `cosign key` (with `--key`), `none`; `provenance` = `actions/attest` (or `attest-build-provenance`) / `none`. A field that is `none` is a finding for the adoption plan (`/harden supply-chain`), not a `[TO BE CONFIGURED]`.
- LLM features: `none` unless a manifest names an LLM or MCP SDK — `@anthropic-ai/sdk`, `@modelcontextprotocol/sdk`, `@modelcontextprotocol/server`, `@modelcontextprotocol/client` in `package.json`; `anthropic`, `mcp` in `requirements.txt` / `pyproject.toml`; `github.com/anthropics/anthropic-sdk-go`, `github.com/modelcontextprotocol/go-sdk` in `go.mod`; `anthropic-ai/sdk`, `mcp/sdk` in `composer.json`. A hit fills `llm_provider_sdk` from the package, `llm_model` from the model id literal in the code (`grep -rE 'claude-[a-z0-9-]+'`, else `[TO BE CONFIGURED]`), `mcp_role` from what is imported (`@modelcontextprotocol/server` / `MCPServer` / `mcp.Server` → `server`; client classes or `mcp_servers` request params → `client`; both → `client+server`), `llm_eval_set` from an existing eval directory (`tests/llm/`, `evals/`) else `none`, `llm_injection_controls` `none` until `/threat-model llm` records them; the finding "LLM feature without an eval set / threat-model rows" is HIGH (`stack-reference/llm-integration.md`).
- Layout: `backend_root`, `frontend_root`, `go_layout`, `go_architecture` and its companions, `php_framework`, `php_architecture` and its companions (`references/detect-go.md`, `references/detect-php.md`).
